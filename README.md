# Text-to-Morse-Code Converter

A simple Python project that converts text (letters, numbers, and spaces) into Morse code.
This tool allows users to type in words, sentences, or numbers and get the corresponding Morse code translation.

---

### Features

Converts letters (A–Z) and numbers (0–9) into Morse code.

Handles spaces between words using /.

Keeps asking for input until the user types END to terminate communication.

Provides feedback for unknown characters.
